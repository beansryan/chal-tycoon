Each package contains mobile, computing, gaming, audio and accessories fixtures; checkout; empty display; plant; boxes; compact mobile kiosk; packing bench; service desk; stock shelf; store totem; and TV/audio wall. Runtime alpha trimming uses authored crop rectangles rather than assuming an evenly generated grid. Item thumbnails, build ghosts, occupied displays and both checkouts select the same collection.

Floor profiles are stored with the designs and used for rendering, hit testing and placement. Themes can be inspected with an ephemeral developer location override; paid expansion state and fixture coordinates remain intact. The actual Challenger logo silhouette is retained and tinted for contrast against each fascia.

Real location references: https://online.challenger.sg/pages/stores and https://www.jewelchangiairport.com/en/shop/challenger.html . ION uses B3-15/16, Jewel B2-214/215/216, Funan 03-27/28, PLQ 04-01. Environments are illustrative interpretations; SG Tech Megastore is fictional.

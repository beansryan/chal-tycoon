# Visual direction · October 2026

The latest user references set the art direction: detailed, warmly shaded pixel environments; consistent chibi characters; small readable game controls. The original artwork is created for this project. Reference images and commercial game art are not redistributed.

## Games reviewed

- [Good Pizza, Great Pizza](https://store.steampowered.com/app/770810/Good_Pizza_Great_Pizza/): storefront screenshots show a large playable scene, compact money/day counters, and controls related to the current interaction. Adopt the emphasis on the shop, and short character dialogue.
- [Convenience Stories](https://store.steampowered.com/app/2119650/Convenience_Stories/): developer storefront screenshots show coherent pixel fixtures, customers and store floors, with inventory/management menus opened over the game. Adopt illustrated fittings, a consistent asset palette and contextual stock controls.
- [Two Point Museum](https://store.steampowered.com/app/2185060/Two_Point_Museum/): the world carries the scene, while management tools and objectives sit at its edges. Adopt resource counters and a single milestone ticket.
- [Animal Crossing: New Horizons](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Animal-Crossing-New-Horizons-1438623.html): character-led dialogue and inventory presentation informed the small dialogue bubble and illustrated build tray.

These are design interpretations of visual references, not claims that this game reproduces their systems. The implementation uses original art and UI.

## Changes

The permanent dashboard and brand header are removed from play. The full-screen shop gets a wood-framed action tray, cash and level counters, a small milestone ticket and day/weather tags. Stock, pricing, supplier deliveries, staffing, research and reports open on demand. Touch placement uses a preview and confirmation. Original full-body pose atlases replace cropped heads and procedural body parts. Walk, browse and cashier cycles keep feet aligned; reduced motion stops pose cycling.

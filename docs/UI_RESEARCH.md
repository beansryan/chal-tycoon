# Visual direction · October 2026

The latest user references set the art direction: detailed, warmly shaded pixel environments; consistent chibi characters; small readable game controls. The original artwork is created for this project. Reference images and commercial game art are not redistributed.

## Games reviewed

- [Good Pizza, Great Pizza](https://store.steampowered.com/app/770810/Good_Pizza_Great_Pizza/): storefront screenshots show a large playable scene, compact money/day counters, and controls related to the current interaction. Adopt the emphasis on the shop, and short character dialogue.
- [Convenience Stories](https://store.steampowered.com/app/2119650/Convenience_Stories/): developer storefront screenshots show coherent pixel fixtures, customers and store floors, with inventory/management menus opened over the game. Adopt illustrated fittings, a consistent asset palette and contextual stock controls.
- [Two Point Museum](https://store.steampowered.com/app/2185060/Two_Point_Museum/): the world carries the scene, while management tools and objectives sit at its edges. Adopt resource counters and a single milestone ticket.
- [Animal Crossing: New Horizons](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Animal-Crossing-New-Horizons-1438623.html): character-led dialogue and inventory presentation informed the small dialogue bubble and illustrated build tray.

These are design interpretations of visual references, not claims that this game reproduces their systems. The implementation uses original art and UI.

## Changes

The permanent dashboard and brand header are removed from play. The full-screen shop gets a charcoal/cyan action tray, cash and level counters, a small milestone ticket and day/weather tags. Stock, pricing, supplier deliveries, staffing, research and reports open on demand. Touch placement uses a preview and confirmation. Original full-body pose atlases replace cropped heads and procedural body parts. Walk, browse and cashier cycles keep feet aligned; reduced motion stops pose cycling.

## Mall scenery update

The user's latest Jewel sample guides the relationship between indoor garden, glass roof, promenade and shop frontage. Original replacement assets depict this setting, with one connected scene so garden, neighboring stores, shop and corridor share the camera. [Jewel's official Rain Vortex page](https://www.jewelchangiairport.com/en/attractions/rain-vortex.html) and [Forest Valley page](https://www.jewelchangiairport.com/en/attractions/forest-valley.html) ground the real-location landmarks. The game room and surrounding architecture are an illustrative interpretation.

## Layout editing reference

[Supercell's Clash of Clans UI update](https://supercell.com/en/games/clashofclans/blog/news/weve-revamped-the-clash-of-clans-user-interface/) documents contextual Build/Edit Layout controls and a live world behind menus. The user specifically requested the Clash-style editing feel. Our implementation interprets that request as an immediate movable preview, snapped footprints, green/red placement status and explicit confirmation/cancellation. It retains the shop simulation's own footprint and customer-route rules; it does not copy Clash assets or claim to reproduce its exact editor.
